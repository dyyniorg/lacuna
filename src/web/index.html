First review: buildings

Copy a cell's OSM download URL and open buildings.osm. Review the geometries and save it, then select that cell and run the next step.

  1. Paste the copied OSM download URL into JOSM.
  2. Open the cell's buildings.osm path in JOSM.
  3. Review the new buildings. Remove lacuna:review when checked. Keep lacuna:ref.
  4. Save buildings.osm back to the same path.
  5. Select the reviewed cell and click Run adjust.

Adjust addresses

Select a cell you have reviewed and saved in JOSM.

Adjust report

Final review

Open the adjusted addresses.osm in JOSM, run apply_addresses.js on the downloaded OSM layer, merge buildings.osm, remove all lacuna:* tags, and upload only the downloaded OSM layer.
