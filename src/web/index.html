Review

Review each cell's address proposals in JOSM, apply them to the OSM data, and mark the cell done.

  1. Copy the cell's OSM URL from the table and paste it into JOSM.
  2. Open the cell's addresses.osm layer in JOSM.
  3. Review the address proposals.
  4. Make the downloaded OSM layer active and run the apply_addresses.js script to copy the addr:* tags from the review layer to the matching OSM buildings.
  5. Make sure there are no leftover lacuna:* tags, then upload the changes to OSM.
