Review

Review each cell's buildings, adjust the addresses, and upload the changes. Cells marked Skipped have no building proposals and do not need Adjust; review their addresses directly.

  1. Copy the cell's OSM URL from the table and paste it into JOSM.
  2. Open the cell's buildings.osm path in JOSM.
  3. Review the new buildings. Remove lacuna:review when checked. Keep lacuna:ref.
  4. Save buildings.osm back to the same path.

Once the cell is ready for address review, open only its addresses.osm layer in JOSM, activate the downloaded OSM data layer, and run apply_addresses.js. The script moves the address tags onto the OSM data layer. Merge buildings.osm when the cell has that file, remove all lacuna:* tags, and upload only the downloaded OSM data layer.
